Цель: создать оконное приложение "Дневник Путешествий"

Общее описание: Приложение, в котором пользователи смогут оставлять заметки о впечатлениях от путешествий в формате дневника, искать новые и добавлять свои места, а также сохранять те места, в которых хотят побывать.

Требования к функционалу:

Главное окно должно иметь 3 вкладки: "Главная", "Дневник" и "Вишлист"

Вкладка "Главная"(Home) должна содержать: 
строку поиска(QLineEdit) с кнопкой(QPushButton) "Найти" в верхней части окна
кнопку(QPushButton) "Добавить место" справа от строки поиска
никнейм пользователя(QLabel) слева от строки поиска
GridLayout со случайно выбранными местами для путешествий, картинками и кратким описанием
Нажатие на кнопку "Добавить место" должно вызывать виджет добавления места(AddPlaceWidget). 
Когда пользователь вписывает что-то в строку поиска и нажимает кнопку "Найти"(или просто нажимает кнопку) открывается QStackedWidget поиска.

Вкладка "Дневник"(DiaryWidget) должна содержать:
надпись "Дневник" в верхней части окна
фильтрацию
записи пользователя в порядке их создания
Фильтрация должна осуществляться тремя способами: по стране с помощью QComboBox; по году, когда была сделана запись с помощью QComboBox; по месяцу, когда была сделана запись с помощью QComboBox; по местам отмеченным, как любимые с помощью QCheckBox.

Вкладка "Вишлист"(WishlistWidget) должна содержать:
надпись "Вишлист" в верхней части окна
фильтрацию по стране с помощью QComboBox
места, добавленные пользователем в порядке добавления.

Виджет поиска(SearchWidget) должен содержать:
строку поиска(QLineEdit) с кнопкой(QPushButton) "Найти" в верхней части окна
ниже должны выводиться все совпадения с введенными данными в строку пользователя
Совпадения следует искать в названиях мест для путешествий, странах и местоположениях.
Нажатие на определенное место путешествия открывает QStackedWidget странички этого места.

Виджет странички места(PlaceCard) должен содержать: 
фотографию или несколько фотографий в левой верхней части окна
справа от фото должны быть написаны: название, страна и более точное местоположение
ниже должна располагаться более точная информация
кнопки(QPushButton) "Добавить в вишлист", добавляющую место в вишлист, и "Создать запись", вызывающую виджет создания записи в дневнике

Виджет добавления места(AddPlaceWidget) должен содержать:
кнопку() для добавления фото, вызывающую QFileDialog, и место для его отображения
поле для ввода названия, страны и более подробного местоположения
поле для ввода информации о добавляемом месте

Виджет добавления записи в дневник(AddDiaryList) должно содержать:
выбор даты
кнопку для добавления фото, вызывающую QFileDialog 
поле для ввода текста
кнопку "Добавить", добавляющую запись в дневник и закрывающую текущее окно

Требования к технологиям:
Python 3.13+
PyQt6
SQLite

Критерии приёмки:
Все функции работают
